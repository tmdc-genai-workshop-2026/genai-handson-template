# genai-handson

生成AIワークショップ（実習）用のリポジトリです。このリポジトリは、講師が用意したテンプレートから作った、あなた専用のコピーです。

- `sample_data/articles/`: ネットワークが使えないときなどに使う、**架空の**記事セット（実在の出来事ではありません）
- `sample_data/draft_mail.txt`: レビューの練習用に使える、**架空の**メールの下書き
- `output/`: スキルの出力先
- `.claude/skills/`: あなたが作るスキルが置かれる場所（実習中に作成されます）
- `protected.txt`: 書き換え禁止のファイル（`.claude/settings.json` で保護しています）

注意: このリポジトリに、機密情報・個人情報・パスワードやAPIキーを入れないでください。
